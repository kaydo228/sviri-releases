# Sweetie Voice

Скачайте Sweetie Voice для Windows x64 или Mac с Apple Silicon с [официального сайта](https://sviri.vercel.app/).

В 0.2.24 «Магнитофон» показывает спектр по всей окружности аватарки. «Волна» расходится кольцами, а прежний водный эффект сохранён как «Прилив». Молнии, звёзды и лазер становятся ярче вместе с голосом. Выбор эффекта доступен прямо в звонке. [Список изменений и установщики 0.2.24](https://github.com/kaydo228/sviri-releases/releases/tag/v0.2.24)

Если окно обновления зависло в старой версии, закройте приложение и установите актуальную версию с сайта поверх имеющейся. Профиль и история комнат сохранятся.
