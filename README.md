# Sweetie Voice

Скачайте Sweetie Voice для Windows x64 или Mac с Apple Silicon с [официального сайта](https://sviri.vercel.app/).

В 0.2.25 оверлей Windows сам распознаёт поддерживаемые игры во время звонка. Молнии бегут по контуру аватарки и реагируют на акценты речи, а звёзды пролетают по встречным дугам. По нажатию на номер версии открывается история пяти последних выпусков. [Список изменений и установщики 0.2.25](https://github.com/kaydo228/sviri-releases/releases/tag/v0.2.25)

Если окно обновления зависло в старой версии, закройте приложение и установите актуальную версию с сайта поверх имеющейся. Профиль и история комнат сохранятся.
