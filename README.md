# Sweetie Voice

Скачайте Sweetie Voice для Windows x64 или Mac с Apple Silicon с [официального сайта](https://sviri.vercel.app/).

Версию 0.2.28 можно установить из приложения для Windows x64 и Mac с Apple Silicon. Выйдите из комнаты, откройте уведомление об обновлении и нажмите «Установить и перезапустить». В новой версии кнопка проверки обновлений всегда видна над настройками, а хост может принять запрос по коду с открытым окном приглашения. [Список изменений и установщики 0.2.28](https://github.com/kaydo228/sviri-releases/releases/tag/v0.2.28)

Если окно обновления зависло в старой версии, закройте приложение и установите актуальную версию с сайта поверх имеющейся. Профиль и история комнат сохранятся.
