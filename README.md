# Sweetie Voice

Скачайте Sweetie Voice для Windows x64 или Mac с Apple Silicon с [официального сайта](https://sviri.vercel.app/).

В 0.2.27 у Sweetie Voice появился новый маскот — мятная лиса. Индикатор «Молнии» выстреливает пучками из случайных точек на краю аватарки, а громкие слоги вызывают более яркие вспышки. [Список изменений и установщики 0.2.27](https://github.com/kaydo228/sviri-releases/releases/tag/v0.2.27)

Если окно обновления зависло в старой версии, закройте приложение и установите актуальную версию с сайта поверх имеющейся. Профиль и история комнат сохранятся.
