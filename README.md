# Sweetie Voice

Скачайте Sweetie Voice для Windows x64 или Mac с Apple Silicon с [официального сайта](https://sviri.vercel.app/).

В 0.2.26 молнии и звёзды вылетают от края аватарки в разные стороны. Во время речи все девять индикаторов показывают живой спектр голоса. Выбрать свой эффект можно под аватарками прямо в звонке. [Список изменений и установщики 0.2.26](https://github.com/kaydo228/sviri-releases/releases/tag/v0.2.26)

Если окно обновления зависло в старой версии, закройте приложение и установите актуальную версию с сайта поверх имеющейся. Профиль и история комнат сохранятся.
