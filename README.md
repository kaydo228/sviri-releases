# Sweetie Voice

Скачайте Sweetie Voice для Windows x64 или Mac с Apple Silicon с [официального сайта](https://sviri.vercel.app/).

В 0.2.23 под аватарками можно выбрать свой индикатор речи. Появились «Волна», «Молнии», «Звёзды», «Лазер» и «Магнитофон». Собеседники увидят выбранный эффект, когда вы говорите. Теперь можно открывать чаты других сохранённых комнат во время разговора. [Список изменений и установщики 0.2.23](https://github.com/kaydo228/sviri-releases/releases/tag/v0.2.23)

Если окно обновления зависло в старой версии, закройте приложение и установите актуальную версию с сайта поверх имеющейся. Профиль и история комнат сохранятся.
