# Sweetie Voice

Скачайте Sweetie Voice для Windows x64 или Mac с Apple Silicon с [официального сайта](https://sviri.vercel.app/).

В 0.2.40 каждый выбирает фон звонка для себя и может предложить его друзьям. Список каналов сворачивается до значков, а во время речи аватар остаётся виден. В чате можно отправлять GIF и обмениваться наборами стикеров. После смены сети приложение продолжает попытки вернуться в голосовой канал. [Скачать 0.2.40](https://github.com/kaydo228/sviri-releases/releases/tag/v0.2.40)

В 0.2.39 можно перетаскивать файлы в чат и открывать изображения на весь экран. У ярлыка приложения появилась круглая подложка.

Автообновление повторяет запрос при временной ошибке сети. Если хост снова открывает комнату, гости на 0.2.39 возвращаются из продолжающегося звонка в тот же голосовой канал. Исправлено ложное сообщение «Канал связи закрыт» при выходе собеседника. [Скачать 0.2.39](https://github.com/kaydo228/sviri-releases/releases/tag/v0.2.39)

В версии 0.2.38 внизу звонка одна зелёная волна, высота которой меняется с громкостью разговора. [Список изменений и установщики 0.2.38](https://github.com/kaydo228/sviri-releases/releases/tag/v0.2.38)

С версии 0.2.37 картинку или GIF на фоне голосового канала видят все участники. Если вы выключите спектр голоса, собеседники увидят вашу аватарку и анимацию вокруг неё. Внизу звонка снова одна общая волна. После выхода хоста из обычной комнаты уже подключённые участники могут продолжить разговор. [Список изменений и установщики 0.2.37](https://github.com/kaydo228/sviri-releases/releases/tag/v0.2.37)

Начиная с версии 0.2.36 Sweetie Voice проверяет и устанавливает обновления в небольшом окне при запуске. Чтобы получить новую версию, полностью закройте приложение и откройте его снова.

Чтобы обновиться с версий 0.2.31–0.2.35, нажмите кнопку обновления над настройками и выберите «Установить и перезапустить». Если вы в комнате, окно установки предложит выйти из неё. Хост увидит предупреждение о закрытии комнаты.

Для перехода с 0.2.30 откройте меню комнаты и выберите «Покинуть комнату» или «Закрыть комнату», затем нажмите кнопку обновления над настройками. Если кнопка остаётся серой, полностью закройте приложение и откройте его снова. Начиная с 0.2.31 выйти из комнаты можно прямо при установке обновления.

На Mac с Apple Silicon версию 0.2.35 ещё устанавливает прежний клиент. Если после установки появилась ошибка `ENOTEMPTY`, один раз полностью выйдите из Sweetie Voice через **⌘Q**. Если приложение не открылось само, запустите его снова. Версия 0.2.35 уже содержит исправленный установщик. При следующих обновлениях приложение удаляет старую копию и автоматически перезапускается с прежним профилем.

Если окно обновления зависло в старой версии, закройте приложение и установите актуальную версию с сайта поверх имеющейся. Профиль и история комнат сохранятся.
