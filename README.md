# Sweetie Voice

Скачайте Sweetie Voice для Windows x64 или Mac с Apple Silicon с [официального сайта](https://sviri.vercel.app/).

Чтобы обновиться до 0.2.30, выйдите из комнаты, нажмите кнопку обновления над настройками и выберите «Установить и перезапустить». В этом выпуске появились уведомления о сообщениях во время звонка, счётчики непрочитанных, индикатор набора и GIF-аватарки. Из лобби можно изменить или удалить свою комнату. [Список изменений и установщики 0.2.30](https://github.com/kaydo228/sviri-releases/releases/tag/v0.2.30)

На Mac с Apple Silicon версия 0.2.28 может показать ошибку `ENOTEMPTY` после установки 0.2.29. Если видите эту ошибку, нажмите **⌘Q**, чтобы полностью закрыть Sweetie Voice. В проверке после этого приложение само запустилось с версией 0.2.29 и сохранённым профилем.

Если окно обновления зависло в старой версии, закройте приложение и установите актуальную версию с сайта поверх имеющейся. Профиль и история комнат сохранятся.
