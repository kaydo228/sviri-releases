# Sweetie Voice

Скачайте Sweetie Voice для Windows x64 или Mac с Apple Silicon с [официального сайта](https://sviri.vercel.app/).

Чтобы обновиться с 0.2.28 до 0.2.29, выйдите из комнаты, нажмите кнопку обновления над настройками и выберите «Установить и перезапустить». В этом выпуске появились постоянные комнаты на VPS, роли участников, вложения и стикеры в чате. [Список изменений и установщики 0.2.29](https://github.com/kaydo228/sviri-releases/releases/tag/v0.2.29)

Если окно обновления зависло в старой версии, закройте приложение и установите актуальную версию с сайта поверх имеющейся. Профиль и история комнат сохранятся.
