# Sweetie Voice

Скачайте Sweetie Voice для Windows x64 или Mac с Apple Silicon с [официального сайта](https://sviri.vercel.app/).

В 0.2.33 появился режим шумоподавления «Сильное». Выберите его в панели звонка или в настройках звука, чтобы приглушить гул компьютера и щелчки клавиатуры. [Список изменений и установщики 0.2.33](https://github.com/kaydo228/sviri-releases/releases/tag/v0.2.33)

Чтобы обновиться с 0.2.31 или 0.2.32, нажмите кнопку обновления над настройками и выберите «Установить и перезапустить». Если вы в комнате, окно установки предложит выйти из неё. Хост увидит предупреждение о закрытии комнаты.

Для перехода с 0.2.30 откройте меню комнаты и выберите «Покинуть комнату» или «Закрыть комнату», затем нажмите кнопку обновления над настройками. Если кнопка остаётся серой, полностью закройте приложение и откройте его снова. Начиная с 0.2.31 выйти из комнаты можно прямо при установке обновления.

На Mac с Apple Silicon при обновлении с 0.2.32 до 0.2.33 может появиться ошибка `ENOTEMPTY`. Если она появилась, нажмите **⌘Q**, чтобы полностью выйти из Sweetie Voice. При проверке после выхода приложение само открылось с версией 0.2.33 и прежним профилем. Такой же шаг помогал при обновлении с версий 0.2.28–0.2.31.

Если окно обновления зависло в старой версии, закройте приложение и установите актуальную версию с сайта поверх имеющейся. Профиль и история комнат сохранятся.
