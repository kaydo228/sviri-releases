# Sweetie Voice

Скачайте Sweetie Voice для Windows x64 или Mac с Apple Silicon с [официального сайта](https://sviri.vercel.app/).

В 0.2.31 логотип, версия и текущий канал собраны в заголовке окна. В лобби внизу боковой панели видны ваша аватарка и имя, а в комнате — одна карточка профиля с ролью. Новые GIF-аватарки сохраняют больше деталей. Чтобы заменить уже сжатую аватарку, выберите исходный GIF повторно. [Список изменений и установщики 0.2.31](https://github.com/kaydo228/sviri-releases/releases/tag/v0.2.31)

Для перехода с 0.2.30 откройте меню комнаты и выберите «Покинуть комнату» или «Закрыть комнату», затем нажмите кнопку обновления над настройками. Если кнопка остаётся серой, полностью закройте приложение и откройте его снова. Начиная с 0.2.31 выйти из комнаты можно прямо при установке обновления.

На Mac с Apple Silicon при переходе с 0.2.30 на 0.2.31 после установки может появиться ошибка `ENOTEMPTY`. Нажмите **⌘Q**, чтобы полностью закрыть Sweetie Voice. При проверке приложение затем само открылось с версией 0.2.31 и сохранённым профилем. Этот шаг также помогал при обновлениях с 0.2.28 и 0.2.29.

Если окно обновления зависло в старой версии, закройте приложение и установите актуальную версию с сайта поверх имеющейся. Профиль и история комнат сохранятся.
